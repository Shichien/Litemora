# 方块渲染约定

游戏静态原理图、回放运动层和上传预览使用同一方块材质转换。纹理颜色作为 sRGB 解码，在线性空间执行材质计算，再由最终输出编码为 sRGB；不得额外加入 `pow(rgb, 2)` 之类的预览补偿。

默认关闭电影式 ACES 和 Bloom，保留原始像素贴图与透明度。方向面亮度参考 vanilla：顶部 1、底部 0.5、东西面 0.6、南北面 0.8，以世界法线计算，因此转动视角不改变面亮度。已有顶点 tint、alpha test、透明混合和资源包贴图须保留。静态及动态路径共用昼夜亮度，管理预览固定为日光。

## 天空光、方块光和邻接 AO

游戏世界在 Worker 中从原理图全部区域构建独立体素光场，天空光和方块光分别保存为 0..15。天空直下经过空气不衰减，转向传播逐格衰减；水、树叶、遮光玻璃按光学属性衰减或阻断。方块光从光源向六个方向传播，光源关闭或遮挡改变后重新求解，清除旧光。昼夜只改变天空光的呈现，不会熄灭火把等方块光。

GPU 使用同一 RGBA 三维纹理（天空光、方块光、AO 遮挡、源发光），静态结构与运动实例统一采样。每个面按中心、两侧和对角邻居计算四角 AO 与光照，再按面内坐标插值；保留原有材质 tint。参考 [Fabric Indigo AoCalculator](https://github.com/FabricMC/fabric/blob/1.21.5/fabric-renderer-indigo/src/client/java/net/fabricmc/fabric/impl/client/indigo/renderer/aocalc/AoCalculator.java)。这与屏幕空间 SSAO 不同，遮挡来自真实方块数据。

回放渲染会把动态方块从静态网格剥离，因此光场使用独立原始快照加回放状态覆盖。每批状态变化触发一次异步求解，排队合并更新；跳转建立版本界线，防止旧结果覆盖新场景。GPU 在实例实际世界位置取样，不能往共享模板几何写入位置专属颜色。

### 明确的兼容范围

- 光学基础表来自 minecraft-data Java 1.21.11，并补充灯、火把、蜡烛、炉、充能锚、铜灯等逐状态规则；不是 Java 26.1.2 官方逐状态光学转储。未知方块保守遮光并显示提示。
- 半砖、楼梯已按上下半部阻断对应完整水平面，双半砖完整遮光；复杂侧面形状仍采用近似，没有完整复刻原版所有方向形状遮挡。复杂旋转模型的顶点归属也可能不同。不得称为与官方引擎逐像素一致。
- 默认光场上限为 4,194,304 体素，并限制三维纹理单轴尺寸；超过预算时明确显示基础光照提示。当前不以不完整的摄像机窗口冒充全世界天光，避免窗口外屋顶漏光。
- 当前更新在 Worker 中全场重算并合并请求，尚未实现增量减光队列和分区纹理。这会限制大型快速变化电路的更新频率，但不会阻塞主线程进行传播。
- 管理上传预览仍使用稳定日光方向着色，不与游戏世界共享光场。


## 炼药锅兼容

Cubane 1.0.19 把以 `block/water`、`block/lava` 开头的模型误判为流体，导致 `water_cauldron_*`、`lava_cauldron` 跳过父模型解析并变成整格液体。应用层兼容补丁仅将这些炼药锅模型恢复为常规模型父链解析，不修改依赖包，不改变正常水或岩浆模型。静态原理图、回放模板和上传预览均在模型生成前安装补丁。

升级 Cubane 时运行真实资源包回归测试；若上游修复，可以移除兼容补丁。测试须覆盖空锅、水锅三级水位、岩浆锅、细雪锅，以及正常水/岩浆行为保持。
