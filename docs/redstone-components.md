# 上传原理图里的红石元件

本表核对了 Minecraft Java 26.1.2 和 26.3 客户端的红石创造栏（`CreativeModeTabs.REDSTONE_BLOCKS`）。两个版本的清单相同，共 70 项。其中 62 项会放成方块，8 项会生成实体。红石粉和线在原理图中的方块名分别是 `redstone_wire` 和 `tripwire`。上传页会按文件里保存的朝向、状态和库存模拟。[上传和运行方法](./redstone-archive.md#上传原理图并运行红石)

| 元件 | 在原理图中可以观察的行为 |
| --- | --- |
| 红石粉、红石火把、红石块、中继器、比较器、侦测器 | 信号传递、强度衰减、延迟、锁定、比较或相减，以及方块更新脉冲。 |
| 标靶 | 吸引红石线连接。箭、鸡蛋、雪球撞到靶面时按命中位置输出 1 至 15 级信号。箭的脉冲持续 20 游戏刻，鸡蛋和雪球持续 8 刻。 |
| 四种氧化程度的涂蜡铜灯 | 每次通电边沿翻转亮灭，断电后保持。比较器能读取亮灭。 |
| 拉杆、橡木按钮、石按钮、橡木压力板、石压力板、轻质测重压力板、重质测重压力板、绊线钩、线 | 响应操作或实体占用。测重压力板按数量输出；石压力板检测生物类实体，包括普通盔甲架。 |
| 幽匿感测体、校频幽匿感测体、幽匿尖啸体、紫水晶块、白色羊毛 | 两种感测体的范围分别为 8 格和 16 格。校频侧可以选择频率，比较器读取振动频率。羊毛可以遮挡振动，相邻紫水晶块可以传递共振。尖啸体可以响应脚步或来自玩家的感测体激活事件。 |
| 讲台、阳光探测器、涂蜡避雷针、红石矿石 | 讲台能产生翻页脉冲，比较器可读存档中的页码。阳光探测器按模拟环境更新。雷击使避雷针通电 8 刻。踩踏红石矿石会点亮它，随机刻可使它熄灭。 |
| 活塞、黏性活塞、黏液块、蜂蜜块 | 推拉相连结构，检查推动数量和不能移动的方块。蜂蜜和黏液各自黏住相邻负载，彼此不黏。 |
| 发射器、投掷器、合成器、漏斗 | 按朝向发射、投放或转移物品。可发射箭、放置潜影盒、点燃 TNT。合成器从导入的九格材料匹配 1,030 个普通有序和无序配方，消耗原料并输出成品及容器余物。 |
| 箱子、涂蜡铜箱、木桶、雕纹书架、橡木陈列架、熔炉、陷阱箱、唱片机、饰纹陶罐 | 容器可参与相应的比较器读取或漏斗交互。同方向通电的陈列架最多连接三个。熔炉按燃料时长烧炼，可把成品交给下游漏斗。唱片、书架、陶罐的读取依赖文件中保存的物品数据。 |
| 音符盒、堆肥桶、炼药锅、红石灯、钟、大型垂滴叶 | 音符盒、红石灯和钟会响应红石边沿。比较器可读堆肥层数及炼药锅的液面。踩踏垂滴叶会使它分阶段倾斜并复原。 |
| 铁轨、动力铁轨、探测铁轨、激活铁轨 | 车身进入探测区就能触发铁轨，比较器从同一区域读取货车库存。动力铁轨推动矿车，激活铁轨能切换漏斗矿车的吸取状态，并点燃 TNT 矿车。 |
| 矿车、漏斗矿车、运输矿车、动力矿车、TNT 矿车 | 导入的五种矿车可以沿轨道行驶并触发探测铁轨。容器矿车能参与你的物品搬运线路，动力矿车读取存档中的燃料和推力，沿轨道推走前方货车。漏斗矿车会保留存档里的吸取开关。 |
| 橡木运输船、竹运输筏、盔甲架 | 漏斗可从运输船和运输筏中取货。盔甲架能下落到石压力板、碰触高处绊线，并能在贴近时推动普通矿车。小型盔甲架的身高和宽度减半，Marker 定位架忽略这些触发。 |
| 橡木门、铁门、橡木栅栏门、橡木活板门、铁活板门、TNT | 红石供电驱动门和活板门。TNT 点燃后等待引信，按方块爆炸抗性破坏周围结构，可以连锁引爆。 |

### 利用实体的机关

| 原理图里的搭法 | 已验证的结果 |
| --- | --- |
| 动力矿车、运输矿车、探测铁轨、比较器 | 动力矿车把载货的运输矿车推入车站，比较器读到货物并点灯。移走动力矿车，货车留在原位。 |
| 灵魂沙、水源、盔甲架、绊线钩 | 初始水源在 20 游戏刻后形成连续的上升气泡柱，盔甲架升高触线后点灯。岩浆块生成向下的气泡柱，流动水会截断气泡柱。移走底座后，原处恢复为水源。 |
| 高处绊线、石压力板、盔甲架 | 下落的盔甲架先经过绊线，再落到板上。普通盔甲架的身体能够触到脚所在方格上方的线，小型架与标记架在同一位置有不同结果。 |

动力矿车编组和漏斗矿车分拣都有玩家公开的装置演示。上述测试使用小型独立电路，方便观察哪个元件产生了输出。[ilmango 的动力矿车演示](https://www.youtube.com/watch?v=pRLiAQfhTG8) · [ilmango 的漏斗矿车分拣器](https://www.youtube.com/watch?v=hiR5bu1aWrU)

**验证范围。** 自动测试逐项检查 62 个放置状态及其内置方块资源。行为测试另外搭建了标靶驱动铁活板门、羊毛隔音、紫水晶中继、蜂蜜活塞、合成器向铜箱送料、熔炉向木桶出料、矿车到站亮灯、运输船卸货和盔甲架压板等电路。11 份真实机器也从原始文件进入浏览器模拟，其中 8 份产生方块变化，另 3 份从保存状态空跑 10 秒没有输出。[测试用例](../tests/redstone-components.test.mjs)

**机器边界。** 世界面板回放的是方块和活塞的变化。轨道上的信号和箱内物品转移会参与运算，界面目前不会逐帧绘制车辆、箭和掉落物。水平水流传播、船随水流漂移、矿车载人和离轨运动、移动活塞弹射盔甲架、生物生成、爆炸掉落回收，以及烟花、药水等特殊发射物的完整行为仍有缺口。合成表覆盖普通配方，复制书、地图等依赖物品数据的特殊配方另有规则。需要持续投料的装置必须在原图里带上物品。

Java 26.2 和 26.3 正式版导出的原理图也可以运行。模拟采用 26.1.2 的规则，文件若含有该版本无法识别的方块或状态，上传试运行会指出具体问题。26.3 更改了方块名称和属性在存档中的写法，解析和预览都支持这次变更。[Mojang 26.3 更新说明](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-3)

方块状态和配方以 Mojang 26.1.2 客户端为准。碰撞形状及爆炸抗性取自 PrismarineJS 的 26.1 数据，生成时校验了 26.1.2 全部 1,168 种方块的状态编号范围及默认状态。[redstone-rs 引擎](https://github.com/azazo1/redstone-rs) · [碰撞形状数据](https://github.com/PrismarineJS/minecraft-data/blob/master/doc/blockCollisionShapes.md)
